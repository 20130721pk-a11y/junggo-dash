저장한 검색

    찾는 물건을 검색으로 저장해 두면 새로고침할 때마다 세 마켓 매물을 모아 와요.

    잠긴 매물판이에요

    GitHub 저장소 설정에 넣은 비밀번호(DASH_PASSWORD)를 넣어 주세요.

    비밀번호는 이 기기 밖으로 나가지 않아요. 검색어와 모은 매물은 이 비밀번호로 잠겨 있어서 주소를 아는 사람도 비밀번호 없이는 볼 수 없어요.

    매물판을 불러오는 중이에요

    중고나라·번개장터 매물을 저장한 검색별로 모아 보고, 시세와 새로 올라온 매물을 한눈에 확인해요.

    1. 찾는 물건을 검색으로 저장해요. 빼고 볼 단어와 가격대도 정할 수 있어요.
    2. 검색을 저장한 뒤 위에 나오는 'GitHub에 보내기'를 누르고, GitHub 화면에서 초록색 Create(또는 Submit new issue) 버튼을 눌러 주세요. 그다음부터 GitHub가 한 시간마다 중고나라·번개장터를 검색해 와요.
    3. 다시 열면 새로 올라온 매물에 노란 표시가 붙어요.
    4. 필요 없는 매물은 숨기고, 눈여겨볼 매물은 ☆를 눌러 관심 목록에 모아 둬요. 숨김·관심은 이 기기에만 저장돼요.
    5. 당근은 GitHub 서버(해외)에서는 검색되지 않아 빠져요. 당근 매물은 꿀매 레이더 앱에서 보세요.

      자주 나오는 단어누르면 빼기 → 한 번 더 누르면 그 단어만

        고르면 세 마켓 모두 그 카테고리 안에서만 찾아요. 판매자가 다른 카테고리에 올린 매물은 빠질 수 있어요.

        쉼표로 나눠 적어요. 제목에 하나라도 들어가면 목록에서 빼요.

        검색할 마켓

        당근은 GitHub 서버(해외)에서는 검색되지 않아 빠져요.

        검색어 확인

        내용까지 보면 더 많이 찾는 대신 관련 없는 매물이 조금 섞여요. 중고나라·번개장터는 사이트 검색 결과를 그대로 보여줘요.

        오래 안 팔린 매물은 가격을 깎을 여지가 커요.

        추가 옵션

        설정

        시·도와 시·군·구를 적어 주세요(예: 경기도 시흥시, 서울 강남구). 판매 지역이 여기인 매물에 '근처'가 붙고 '가까운 동네만'으로 볼 수 있어요. 바꾸면 GitHub에 보내야 다음 수집부터 반영돼요.
